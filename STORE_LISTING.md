# DownGo — Microsoft Store Listing Text

## App name
DownGo — Fast Download Manager

## Short description (≤200 characters)
Accelerate, pause, resume, and organize your downloads automatically — with a browser extension, custom themes, and Pro acceleration modes.

## Full description

DownGo is a fast, modern download manager for Windows. It splits files into
multiple simultaneous connections to download at your full internet speed,
resumes broken or paused downloads exactly where they left off, and keeps
your downloads folder tidy by automatically sorting files into Documents,
Music, Videos, Programs, and Compressed folders as they finish.

A companion browser extension for Chrome and Edge quietly takes over your
browser's downloads and hands them to DownGo, so every file gets the
multi-connection speed boost without you having to do anything.

DownGo verifies every completed download with a SHA-256 checksum, supports
authenticated and proxy-based downloads, lets you throttle bandwidth so
downloads don't hog your connection, and can batch-import a whole list of
URLs at once.

Upgrade to Pro for 16-thread acceleration, a download scheduler with
auto-shutdown, one-click ZIP/RAR extraction, an automatic Windows Defender
scan after each download, and a full set of custom themes — including
Aurora Glass, a soft frosted-glass look with your own background image
behind it.

### Key features
- Multi-connection accelerated downloads (up to 16 threads with Pro)
- True pause/resume with byte-range resume support
- Automatic file-type sorting into subfolders
- SHA-256 checksum verification on every completed download
- Chrome/Edge browser extension — auto-intercepts downloads
- Batch URL import — paste a whole list at once
- Bandwidth speed limiting and proxy/auth support
- Live speed test tool (Pro)
- Download scheduler with optional auto-shutdown (Pro)
- Auto-extract ZIP/RAR after download (Pro)
- Automatic antivirus scan after download (Pro)
- 9 custom themes, including the frosted-glass "Aurora Glass" look (Pro)
- Custom background image behind the UI, with one-click reset (Pro)
- Custom accent color (Pro)
- System tray integration — runs quietly in the background
- Soft, adaptive window layout that adjusts to your window size
